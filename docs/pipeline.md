# 拍摄与处理管线

## 1. 拍摄（`CameraController`）

白狗照片最常见的毁片原因是白毛过曝：自动测光看整幅画面，深色背景会把曝光拉高，白毛直接变成没有纹理的一片白。**过曝的像素后期救不回来**，所以重点在拍摄端。

1. 取景帧（约 6 Hz）跑 `VNRecognizeAnimalsRequest` + `VNDetectAnimalBodyPoseRequest`，方向 `.right`（竖拍）。
2. 只统计狗框内的亮像素（Y ≥ 150 视为白毛候选），算 Y ≥ 250 的比例和 P95。
3. `FurExposureController`：过曝比例 > 1.5% 就降曝光补偿（过曝越多步子越大，最多 −2 EV）；P95 < 0.86 且几乎没过曝时慢慢回升。
4. 对焦点/测光点放在双眼中点（Vision 坐标 → 传感器坐标的换算在 `VisionGeometry`，有单测）。
5. 「锁定」：锁曝光；白平衡用狗毛中 200–249 亮度段的平均 RGB（线性化）当灰卡，算出让它变中性的增益，打 0.8 折避免把奶油色狗洗成纯白。

## 2. 分析（`FurAnalyzer`，每张照片一次，长边 1536）

1. `VNRecognizeAnimalsRequest` 找狗框。
2. `VNGenerateForegroundInstanceMaskRequest` 前景实例分割，选和狗框重叠最多的实例 → 主体蒙版。
3. `VNDetectAnimalBodyPoseRequest` 取左眼、右眼、鼻子。
4. 干净毛发参考色：主体内、亮、低饱和、非污渍像素的加权平均，迭代两次（第一次找污渍，第二次排除污渍）。
5. 区域先验（只说"在哪儿找"，颜色在内核里逐像素判断）：
   - 泪痕：每只眼内眼角沿眼→鼻方向的椭圆，挖掉眼睛本身；
   - 嘴周：鼻子下方椭圆，挖掉鼻头；
   - 眼鼻：双眼和鼻子的小圆；
   - 全身毛发：主体 × 亮度门限 × 饱和度门限（排除项圈、衣服）。
6. 根据污渍程度、偏色量、过曝比例给出「一键」建议强度。

## 3. 处理（`FurProcessor` + `FurKernels.ci.metal`，线性光）

所有调整都是对原像素**乘比例**，`细节 = 像素 / 模糊底`在整个流程里保持不变，所以每根毛的明暗关系是原图的。

1. **泪痕 / 嘴周**（`bichiDestain`）：污渍概率 = 比干净毛发更暖（R−B 色度差）× 不是暗部。色度拉向这只狗的干净毛色，亮度按"干净毛亮度 / 局部底亮度"提亮（上限 1.6 倍）。
2. **高光**（`bichiHighlight`）：底亮度过 0.62 后进入斜率连续的肩部压缩，同时放大细节比，让接近过曝的白毛重新有层次。完全三通道削顶的像素没有信息，无法恢复。
3. **去黄 / 去灰**（`bichiWhiten`）：以毛发参考色做 von Kries 色适应，只作用在毛发蒙版内且只作用于亮部，背景颜色不变；偏灰时只提亮不压暗，上限 1.35 倍。
4. **眼鼻**（`bichiEyes`）：眼鼻区域内的暗部再压深一点、加局部对比，让眼睛轮廓和高光点出来，并去掉眼眶周围的褐色。

用户画笔：每个区域两层（增加层、擦除层），按笔画顺序回放，最终蒙版 = `max(自动, 增加) × (1 − 擦除)`。

## 4. 需要在真机上调的参数

- 污渍判定阈值 `smoothstep(0.08, 0.35, warmth)`（偏奶油色的狗可能误判）；
- 模糊底的半径（长边 × 0.6%，最小 4 px）——太小会把毛压平，太大会在污渍边缘出光晕；
- 去污渍亮度增益上限 1.6、去灰上限 1.35；
- 曝光控制步长、过曝阈值 1.5%；
- 区域先验椭圆的尺寸（按眼距缩放）。
